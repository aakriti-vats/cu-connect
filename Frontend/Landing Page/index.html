Security & Integrity

Non-negotiable engineering principles that protect student data, ensure auditability, and isolate untrusted code.

Server-Side RBAC

Every role, branch, and year check is re-verified on the server for every request. Client-side hiding is never access control.

Code Sandbox Isolation

IDE execution runs in isolated Docker containers — never on the main app server. CPU, memory, and time limits enforced.

Immutable Audit Trail

Leave approvals and grade changes are append-only logs, not just updated status fields — meaningful admin oversight.

Admin Approval Gate

Teacher and Admin signups require explicit approval — preventing self-elevation of privilege at signup time.

Delivery Roadmap

A phased build — not a single-sprint monolith. Five coordinated sub-projects delivered incrementally.

Phase 1 — Foundation

Auth, RBAC & Attendance

Secure authentication, role-based access control, CHO repository, attendance tracking with bunk calculator, and basic notifications.

Phase 2 — Academics

Results, GPA & Course Catalog

Results module with grade trends, SGPA/CGPA calculator, and multi-department course catalog with theory and MCQ content.

Phase 3 — Workflows

Leave Management

Gate Pass, Medical Leave, and Duty Leave with dual routing, central admin audit, and push notification on status changes.

Phase 4 — Code

Online IDE & Auto-Grading

Sandboxed multi-language IDE with isolated Docker execution and auto-grading for CSE-AIML/AIFT students only.

Phase 5 — Campus

Navigation & Full Notifications

Interactive campus map with search, walking paths, and indoor overlays. Full PWA push notifications with offline queue.
